# Tasks

Todas las casillas empiezan sin marcar. **No se escribe ni una línea de código ni un solo test antes de que el usuario apruebe este change.**

Convenciones de las verificaciones: `cargo test <filtro>` para los tests unitarios de módulo,
`cargo test --test <target>` para los binarios de integración registrados en `Cargo.toml`.
**Los tests nunca hablan con un WordPress real**: las llamadas salientes se prueban contra un
servidor de prueba con `wiremock`, como ya hacen `src/services/wordpress.rs`, `src/services/miniflux.rs`
y `src/services/apimail.rs`.
